## 🎣 海湾钓鱼日

在海湾钓鱼、撒网、赶海，经营鱼市和水族馆的休闲小游戏。纯 HTML/CSS/JS，无需安装任何依赖。

### 运行

直接用浏览器打开 `index.html` 即可，也可以部署到 GitHub Pages 等任意静态网站托管。

### 玩法

- **钓鱼**：点「抛竿」，浮漂抖动时点「收竿」，然后按住按钮（或空格键）收线，进度满了就钓上来。
  - 咬钩后 0.7 秒内收竿算「✨ 完美收竿」，起始进度更高，稀有鱼概率更高。
  - 连续钓上 3 条以上触发「🔥 连击」，每条额外奖励鱼币；鱼跑掉会中断连击。
- **渔网**：撒网后等鱼群游进网里，再一次收网。
- **饵料**：蚯蚓提高稀有鱼概率；虾饵更容易钓到虾蟹和稀有鱼；夜光饵在夜晚大幅提升传说鱼概率。
- **昼夜**：每 2 分钟游戏时间一个昼夜循环，有些鱼只在夜晚出现（图鉴里标 🌙）。
- **钓点**：海湾（默认）、河口（400 币解锁）、深海（1500 币解锁），每个钓点的鱼种不同。
- **鱼类图鉴**：记录钓到过的每种鱼，集齐一个钓点的全部鱼类可领取奖励。
- **鱼市**：买下店铺后上架鱼和珍珠，顾客会来购买。
- **沙滩寻宝**：挖蛤蜊、开珍珠。
- **水族馆**：买馆、买玻璃缸、雇员工、开业收门票；升级装饰可提高门票价格和游客数量。
- **每日登录**：每天第一次打开游戏领取鱼币，连续登录奖励更多（最多每天 350）。

### 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 收线 | 按住按钮或空格 | 按住按钮 |
| 在鱼市/水族馆里走动 | WASD 或方向键 | 右下角方向键 |
| 选择/购买店铺 | E | 右下角 E 键，或直接点店铺 |
| 离开水族馆 | Esc | 左上角按钮 |
| 暂停/继续 | P 或顶部「暂停」 | 顶部「暂停」 |

切换到其他标签页时游戏会自动暂停。

### 存档

- 游戏每 5 秒自动保存到浏览器的 `localStorage`，关闭页面时也会保存。
- 「💾 存档」卡片可以导出存档文件，换浏览器或换设备后再导入。
- 「重新开始今天」会清除存档并重置所有进度。
- 不同网址（例如本地 `file://` 和 GitHub Pages）的存档互相独立。

### 测试

macOS 上装有 Google Chrome 时，可以运行冒烟测试：

```sh
./tests/smoke.sh
```

脚本会在无头 Chrome 里加载游戏，模拟钓一条鱼、暂停、换钓点、进出鱼市等操作，检查没有脚本报错。
