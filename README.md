## 🎣 海湾钓鱼日

在海湾钓鱼、撒网、赶海，经营鱼市和水族馆的休闲小游戏。纯 HTML/CSS/JS，无需安装任何依赖。

### 运行

直接用浏览器打开 `index.html` 即可，也可以部署到 GitHub Pages 等任意静态网站托管。

### 玩法

- **钓鱼**：点「抛竿」（或按空格），浮漂抖动时点「收竿」，然后按住按钮（或空格键）收线，进度满了就钓上来。
  - 每条鱼都有随机尺寸，完美收竿更容易钓到大个的；图鉴会记录每种鱼的最大尺寸，破纪录有提示。
  - 咬钩后 0.7 秒内收竿算「✨ 完美收竿」，起始进度更高，稀有鱼概率更高。
  - 连续钓上 3 条以上触发「🔥 连击」，每条额外奖励鱼币；鱼跑掉会中断连击。
- **渔网**：撒网后等鱼群游进网里，再一次收网。
- **饵料**：蚯蚓提高稀有鱼概率；虾饵更容易钓到虾蟹和稀有鱼；夜光饵在夜晚大幅提升传说鱼概率。
- **昼夜**：每 2 分钟游戏时间一个昼夜循环（清晨、白天、黄昏、夜晚）。白天太阳划过天空，夜晚有月亮、星星、萤火虫和灯光，浮漂在夜里会发光。有些鱼只在夜晚出现（图鉴里标 🌙）。
- **天气**：每分钟可能变化——晴朗、多云、小雨、雷雨（有闪电雷声）、大雾。阴雨天稀有鱼更活跃，雷雨加成最高。
- **钓点**：海湾（默认，有灯塔和帆船）、河口（400 币解锁，有小村庄、石桥、睡莲和垂柳）、深海（1500 币解锁，坐渔船出海，能看到货轮、鲸鱼喷水和飞鱼），每个钓点的鱼种不同。
- **👑 鱼王挑战**：每个钓点都有一条鱼王（海湾巨石斑王、河口江心巨鲶、深海深渊巨齿鲨），需要碳纤维 / 黄金 / 星辰鱼竿以上才能挑战。鱼王咬钩后会不时挣扎（⚠️），挣扎时要松手，鱼线张力满了就会断。征服后奖励大量鱼币（首次双倍），鱼王要休息 6 分钟游戏时间才会回来；失败 45 秒后可以再试。
- **🍳 海鲜料理**：用「我的鱼」做料理，做好马上吃掉获得临时增益——烤鱼串（收线更快）、鲜虾蟹汤（咬钩更快）、豪华刺身（稀有鱼概率更高）、海鲜盛宴（三种效果全有）。会自动挑最便宜的鱼当食材，同类效果时间可叠加（最多 5 分钟）。
- **📋 每日委托**：每天随机 3 个委托（钓鱼、完美收竿、夜钓、连击、收网、挖蛤蜊、开珍珠、做料理、卖货等），各有奖励，全部完成再额外奖励 100 鱼币。
- **📊 统计**：查看总渔获、最高连击、完美收竿次数、开出的珍珠、征服鱼王次数、最大的鱼等。
- **鱼类图鉴**：记录钓到过的每种鱼，集齐一个钓点的全部鱼类可领取奖励。
- **鱼市**：买下店铺后上架鱼和珍珠，顾客会来购买。
- **沙滩寻宝**：挖蛤蜊、开珍珠。
- **水族馆**：买馆、买玻璃缸、雇员工、开业收门票；升级装饰可提高门票价格和游客数量。
- **每日登录**：每天第一次打开游戏领取鱼币，连续登录奖励更多（最多每天 350）。

### 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 抛竿 / 收竿 | 点按钮或空格 | 点按钮 |
| 收线 | 按住按钮或空格 | 按住按钮 |
| 在鱼市/水族馆里走动 | WASD 或方向键 | 右下角方向键 |
| 选择/购买店铺 | E | 右下角 E 键，或直接点店铺 |
| 离开水族馆 | Esc | 左上角按钮 |
| 暂停/继续 | P 或顶部「暂停」 | 顶部「暂停」 |
| 音效音量（大声/小声/静音） | 顶部「🔊」按钮 | 顶部「🔊」按钮 |
| 背景音乐开关 | 顶部「🎵 音乐」 | 顶部「🎵 音乐」 |

切换到其他标签页时游戏默认会自动暂停。在「⚙️ 设置」里取消勾选「离开网页时自动暂停」后，离开网页时游戏继续运行（员工照常工作和领工资、水族馆照常收门票），单次离开最多补算 10 分钟。

音效和背景音乐都由浏览器实时合成，不需要音频文件；白天、夜晚、鱼市和水族馆的背景音乐风格各不相同。浏览器要求先点一下页面才能出声。

### 存档

- 游戏每 5 秒自动保存到浏览器的 `localStorage`，关闭页面时也会保存。
- 「💾 存档」卡片可以导出存档文件，换浏览器或换设备后再导入。
- 「重新开始今天」会清除存档并重置所有进度。
- 不同网址（例如本地 `file://` 和 GitHub Pages）的存档互相独立。

### 测试

macOS 上装有 Google Chrome 时，可以运行冒烟测试（其他系统用 `CHROME=/path/to/chrome` 指定 Chrome 或 Chromium）：

```sh
./tests/smoke.sh
```

脚本会在无头 Chrome 里加载游戏，模拟钓一条鱼、暂停、换钓点、进出鱼市等操作，检查新功能卡片和存档内容，并确认没有脚本报错。
